Проект "Project OOP"

---

## Описание:
На данном этапе работы осуществляется подготовление функций для того, чтобы появилось ядро для интернет-магазина. 
В дальнейшем для этого ядра возможно будет реализовать любой интерфейс — от сайта до телеграм-бота.
---

## Установка:
1. Клонируйте репозиторий:
```
git@github.com:kaverina0208-builder/Project_OOP.git
```
2. Установите зависимости:
```
pip install -r requirements.txt

```

___
## Использование:
В файле ***category.py*** описан класс ***Category*** с атрибутами ***name, description, products***
В файле ***products.py*** описан класс ***Product*** с атрибутами ***name, description, price, quantity***
___

## Тестирование:
В файлах ***test_category.py*** и ***test_product*** написаны тесты для новых классов.
